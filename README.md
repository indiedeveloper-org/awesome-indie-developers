# Awesome Indie Developers

Makers. Hackers. Builders. Find your people at [indiedeveloper.org](https://www.indiedeveloper.org).

## Submit your profile

1. Fork this repository.
2. Copy [the template](examples/profile-with-project-images.json) to `profiles/your-slug.json` and replace the example details.
3. Open a pull request against `main`.

See [CONTRIBUTING.md](CONTRIBUTING.md) for the profile format. To update your profile, edit its file and open another PR.

## Validate locally

Requires Node.js 22 or newer. No dependencies needed.

```sh
node scripts/validate.mjs
```

Pull requests are checked automatically and reviewed before publication.
